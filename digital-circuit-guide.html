第一周：核心概念速成

1.1 数字信号 vs 模拟信号

模拟信号（连续变化）：
电压 ↑
5V  │     ╱╲    ╱╲
    │    ╱  ╲  ╱  ╲
0V  │___╱____╲╱____╲___→ 时间
    声音、温度传感器输出

数字信号（只有 0 和 1）：
电压 ↑
5V  │  ┌──┐  ┌──┐
    │  │  │  │  │
0V  │──┘  └──┘  └───→ 时间
    MCU 的 GPIO 引脚输出
💡 核心理解

数字电路只关心两个状态：高（1）或低（0），中间的过渡过程很快，可以忽略。

1.2 电平标准（最基础但最重要）

TTL 电平（5V 系统，如 Arduino）

输入：
  高电平（1）：≥ 2.0V
  低电平（0）：≤ 0.8V

输出：
  高电平（1）：≥ 2.4V（典型值 5V）
  低电平（0）：≤ 0.4V（典型值 0V）

CMOS 电平（3.3V 系统，如 STM32、ESP32）

VDD = 3.3V 时：
  高电平（1）：≥ 2.0V
  低电平（0）：≤ 0.8V

输出：
  高电平（1）：≈ 3.3V
  低电平（0）：≈ 0V
C - STM32 GPIO 示例 
// STM32 GPIO 输出高电平
HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET);
// 此时 PA5 引脚电压 ≈ 3.3V

// 输出低电平
HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_RESET);
// 此时 PA5 引脚电压 ≈ 0V
❗ 关键问题：5V 和 3.3V 设备能直接连接吗？
Arduino (5V) → STM32 (3.3V)  ❌ 危险！会烧坏 STM32
STM32 (3.3V) → Arduino (5V)  ⚠️  可能无法识别

解决方案：
1. 使用电平转换芯片（如 TXS0108）
2. 使用分压电阻
3. 选择同电平设备

1.3 GPIO 输出模式（通信必备）

推挽输出（Push-Pull）

电路结构：
        VDD (3.3V)
          │
         [P-MOS] ← 控制信号
          │
    ─────┼───── 输出引脚
          │
         [N-MOS] ← 控制信号
          │
         GND

工作原理：
  输出 1：P-MOS 导通，N-MOS 关断 → 引脚连到 VDD → 3.3V
  输出 0：P-MOS 关断，N-MOS 导通 → 引脚连到 GND → 0V
✅ 推挽特点
  • ✅ 能主动输出高/低电平
  • ✅ 驱动能力强（能点亮 LED）
  • ❌ 多个推挽输出不能直接连到一起（会短路）

适用协议：UART TX、SPI（MOSI/MISO/SCK）

开漏输出（Open-Drain）

电路结构：
        VDD (3.3V)
          │
         [上拉电阻 R] ← 外部提供！
          │
    ─────┼───── 输出引脚
          │
         [N-MOS] ← 控制信号
          │
         GND

工作原理：
  输出 0：N-MOS 导通 → 引脚连到 GND → 0V
  输出 1：N-MOS 关断 → 引脚被上拉电阻拉到 VDD → 3.3V
⚠️ 开漏特点
  • ✅ 多个开漏输出可以连到一起（线与逻辑）
  • ✅ 可以实现电平转换
  • ❌ 需要外部上拉电阻
  • ❌ 速度较慢

适用协议：I2C（SCL/SDA 必须开漏）、1-Wire

I2C 典型电路

     VDD (3.3V)
       │
   ┌───┴──┬── 4.7kΩ 上拉电阻
   │      │
  SDA    SCL
   │      │
 ──┴──────┴────  I2C 总线
   │      │
 [设备1] [设备2] ... 所有设备并联

1.4 上拉/下拉电阻（关键概念）

上拉电阻（Pull-Up）

     VDD
      │
     [R] 4.7kΩ
      │
  ────┴──── 信号线
      │
    [开关] ← 未按下时，信号被上拉到 VDD（读到 1）
      │     按下时，信号接地（读到 0）
     GND

应用场景：I2C 总线（强制要求）、按键输入、UART RX 空闲状态

下拉电阻（Pull-Down）

  ────┬──── 信号线
      │
    [开关] ← 未按下时，信号被下拉到 GND（读到 0）
      │     按下时，信号接 VDD（读到 1）
     [R] 10kΩ
      │
     GND
电阻值 特点 适用场景
4.7kΩ - 10kΩ 通用值，平衡功耗和响应速度 I2C、按键输入
< 1kΩ 功耗大，响应快 高速信号
> 100kΩ 功耗低，抗干扰能力弱 极低功耗场景

1.5 时序图阅读（重中之重）

基本符号

上升沿（0 → 1）：        下降沿（1 → 0）：
      ┌─                      ─┐
  ────┘                        └────

高电平保持：             低电平保持：
  ────────                ──────

三态（高阻）：           不确定状态：
  ════════                ╱╲╱╲╱╲

实战案例：UART 发送字节 0x41

波特率 9600bps = 每位持续 104μs

空闲    起始位  D0  D1  D2  D3  D4  D5  D6  D7  停止位  空闲
        (0)     1   0   0   0   0   0   1   0   (1)
   ─┐   ┌──┐   ┌────────────────────┐   ┌──┐   ┌───
    └───┘  └───┘                    └───┘  └───┘
    │   │   │   │   │   │   │   │   │   │   │   │
    │104μs │   │   │   │   │   │   │   │   │   │
    └──────┘   └───────────────────────────┘   └──

LSB 先发送：0x41 = 0b01000001
            从右往左发：1-0-0-0-0-0-1-0
💡 关键点
  • 起始位：必须是 0（从空闲状态下降沿触发）
  • 数据位：LSB（最低位）先发
  • 停止位：必须是 1（回到空闲状态）

SPI 时序图（CPOL=0, CPHA=0）

CS   ────┐                                   ┌────
         └───────────────────────────────────┘

CLK  ────┐ ┌┐ ┌┐ ┌┐ ┌┐ ┌┐ ┌┐ ┌┐ ┌┐ ┌────
         └─┘└─┘└─┘└─┘└─┘└─┘└─┘└─┘└─┘

MOSI ────<D7><D6><D5><D4><D3><D2><D1><D0>──
         主机发送数据

MISO ────<D7><D6><D6><D4><D3><D2><D1><D0>──
         从机发送数据

采样点：CLK 上升沿（↑）读取数据
时序参数 含义
tsu（Setup Time） 数据在时钟沿之前稳定的时间
th（Hold Time） 数据在时钟沿之后保持的时间
tpd（Propagation Delay） 信号传输延迟

实验 1：LED 闪烁（理解电平输出）

材料：Arduino Uno 或任意开发板、LED + 220Ω 电阻

电路连接

  GPIO Pin 13
      │
     [R] 220Ω
      │
     [LED] ← 长脚接正极
      │
     GND
Arduino 
void setup() {
    pinMode(13, OUTPUT);  // 设置为推挽输出
}

void loop() {
    digitalWrite(13, HIGH);  // 输出 5V → LED 亮
    delay(500);
    digitalWrite(13, LOW);   // 输出 0V → LED 灭
    delay(500);
}
🔧 用万用表测量
  • LED 亮时：Pin 13 电压 ≈ 5V
  • LED 灭时：Pin 13 电压 ≈ 0V

实验 2：按键输入（理解上拉电阻）

电路连接

     5V
      │
     [R] 10kΩ ← 上拉电阻
      │
  ────┴──── Pin 2 (INPUT)
      │
    [按键]
      │
     GND
Arduino 
void setup() {
    pinMode(2, INPUT);      // 外部上拉
    // 或者 pinMode(2, INPUT_PULLUP); // 内部上拉
    Serial.begin(9600);
}

void loop() {
    int val = digitalRead(2);
    Serial.println(val);  // 未按下=1，按下=0
    delay(100);
}

最小必要知识自检

如果能回答这些问题，说明数电基础合格：

1. 推挽输出和开漏输出有什么区别？ ▼

推挽能主动输出高/低电平，开漏只能输出低电平，高电平需要外部上拉。

2. I2C 总线为什么必须使用上拉电阻？ ▼

I2C 使用开漏输出，需要上拉电阻将信号拉高，同时允许多个设备共享总线。

3. UART 空闲状态是高电平还是低电平？ ▼

高电平（1），起始位是下降沿（1→0）触发接收。

4. 3.3V 的 MCU 能直接连接 5V 的传感器吗？ ▼

不能！需要电平转换，否则会烧坏 3.3V MCU 的输入引脚。

5. 时序图题：哪个时刻采样数据？ ▼ 
CLK  ──┐ ┌┐ ┌┐ ┌┐ ┌──
       └─┘└─┘└─┘└─┘
DATA ───<1><0><1><0>─

答案：CLK 上升沿（↑）采样，依次读到 1、0、1、0。
